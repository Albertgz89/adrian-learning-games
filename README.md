# Adrian & Aziel's Learning Games

Three learning games — two for a K-1 learner (Adrian) and a dino-themed pre-K/kindergarten-readiness quest for Aziel. Aziel's quest includes a **🎒 Legacy Ready** section: letter names, letter sounds and counting to 30, with a grown-up Flash Check and a progress board. Open index.html — installable as a home-screen app (PWA), works offline.
